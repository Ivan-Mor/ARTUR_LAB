# Лабораторная работа №2 — краткое пояснение

**Тема:** «Объекты JavaScript. Организация хранения данных на клиентской стороне».
**Вариант 2:** посетители поликлиники (ФИО, адрес, телефон, признак оказания стационарной помощи).

## Состав проекта

| Файл | Назначение |
|---|---|
| `index.html` | Ключевой файл: форма заполнения, блок операций, таблица записей, панель результата |
| `js/app.js` | Вся бизнес-логика — только средства языка JavaScript (без библиотек) |
| `css/style.css` | Единый стиль оформления в медицинской тематике |

Запуск: просто открыть `index.html` в браузере (сервер не нужен).

## Как устроено

**Пользовательские объекты (классы):**

- `PatientRecord` — объект одной записи: `id`, `fullName` (ФИО), `address` (адрес), `phone` (телефон), `inpatient` (признак оказания/необходимости стационарной помощи) + динамические свойства, добавленные пользователем.
- `PatientRegistry` — объект-картотека со всеми методами по заданию:
  - `save()` / `load()` — хранение в **WebStorage** (`localStorage`, JSON-сериализация);
  - `addRecord()` — добавление новой записи;
  - `findById()`, `hasId()` — поиск нужного элемента в хранилище;
  - `removeRecord()` — удаление записи по выбранному ID;
  - `getInpatients()` — выборка всех ФИО пациентов, нуждающихся в стационарной помощи;
  - `addProperty()` — добавление нового выбранного свойства объекту;
  - `addInputElementForProperty()` — добавление нового веб-элемента (текстового поля) на страницу для ввода значения нового свойства;
  - `removeProperty()` — удаление выбранного свойства **из всех хранилищ и из объекта** (из записей, списка свойств и localStorage);
  - `showAll()` — метод вывода всех данных на экран (построение таблицы).

**Хранение данных:** массив-хранилище `records` (объект `Array`) + `localStorage`. При первом запуске картотека заполняется 5 демонстрационными записями; все изменения сохраняются и восстанавливаются после перезагрузки страницы.

**Методы `Array` стандарта ECMAScript 6:** `map`, `filter`, `find`, `some`, `reduce`, `includes`, `forEach`.

## Интерфейс (кнопки)

- **Ввести новую запись** — валидация (ФИО, адрес и телефон обязательны, ID уникален, иначе генерируется автоматически) и запись в хранилище.
- **Очистить форму** — сброс всех полей формы.
- **Найти запись по ID** — поиск элемента в хранилище, вывод его данных на экран и в форму.
- **Удалить запись с выбранным ID** — удаление по записи, выбранной в выпадающем списке всех ID.
- **Вывести ФИО пациентов, нуждающихся в стационарной помощи** — filter+map выборка по признаку.
- **Добавить свойство** — выбор свойства из выпадающего списка (телефон учреждения, адрес учреждения, ФИО учредителя, примечание — всего 4), ввод значения: свойство добавляется объекту выбранной записи, на форме появляется новое текстовое поле для этого свойства, в таблице — новый столбец, значение выводится на экран.
- **Убрать свойство** — удаление выбранного из списка добавленного свойства из всех хранилищ и из объектов записей (вместе с его веб-элементом и столбцом таблицы).
