# Лабораторная работа №5 — краткое пояснение

**Тема:** «Асинхронный подход к построению интерактивных пользовательских
интерфейсов веб-приложений (Ajax)».
**Вариант 2:** форма с выпадающим списком ФИО артистов и 3 кнопками:
подгрузка данных из JSON-файла, подгрузка текста из текстового файла,
подгрузка фото и видеоролика об артисте.

## Состав проекта

| Файл | Назначение |
|---|---|
| `server.js` | HTTP-сервер Node.js (встроенные модули `http`, `fs/promises`, `path`): раздача страниц и данных, поддержка Range для видео |
| `html/index.html` | Ключевая страница: блоки `header` / основное содержание / `footer`, форма с выпадающим списком и 3 кнопками |
| `css/style.css` | Единый стиль оформления (CSS3: градиенты, flexbox, grid, тени, transition) |
| `js/main.js` | Клиентский сценарий: асинхронная подгрузка JSON, текста, фото и видео (`fetch`, промисы, `async/await`) |
| `data/*.json` | Данные об артистах (имя, годы, страна, жанр, массив произведений, факт) |
| `data/*.txt` | Биографии артистов текстом |
| `resource/logo.svg` | Логотип проекта |
| `resource/*.svg` | Стилизованные фото-портреты артистов |
| `resource/*.mp4` | Видеоролики об артистах |

Запуск: `npm start` (или `node server.js`), затем открыть http://localhost:3001/.

## Тематика

«Концертный зал»: три классических композитора — П. И. Чайковский,
С. В. Рахманинов, М. И. Глинка. Данные (JSON и TXT) лежат в отдельной
папке `data`, фото и видео — в `resource`.

## Как устроено

**Сервер (`server.js`):**

- маршрутизация: `/` → `html/index.html`, остальное — статические файлы
  из `css/`, `js/`, `data/`, `resource/`;
- чтение всех файлов асинхронное — модуль `fs/promises` (`await fs.readFile`);
- для `.mp4` поддержаны Range-запросы (206 Partial Content) — перемотка в плеере;
- защита от path traversal (`..`, `path.normalize`, префикс `__dirname`);
- никаких сторонних библиотек — только встроенные модули Node.js.

**Клиент (`js/main.js`) — асинхронный обмен по ECMA6:**

- таблица `resources` сопоставляет выбранное ФИО с путями к json/txt/svg/mp4;
- `fetchResource(url)` — общая `async`-функция: `await fetch(url)` +
  проверка `response.ok`, ошибки перехватываются `try/catch` и выводятся в блок;
- **кнопка 1 «Данные артиста (JSON)»** — `await response.json()`, данные
  (имя, годы, страна, жанр, массив произведений, факт) отрисовываются в блок
  «Данные об артисте» (`createElement` + `textContent`);
- **кнопка 2 «Биография (текст)»** — `await response.text()`, текст подгружается
  в заранее заданный блок `#artist-text`;
- **кнопка 3 «Фото и видео»** — в блок `#artist-media` динамически добавляются
  `<img>` (SVG-портрет) и `<video controls>` (mp4-ролик) с `src` выбранного артиста;
- смена артиста в списке + повторное нажатие — подгружаются данные выбранного артиста.
