# Лабораторная работа №4 — краткое пояснение

**Тема:** «Основы программирования на стороне сервера. Введение в Node.js».
**Вариант 2:** массив из 80 элементов со случайными значениями от 1 до 10,
таблица 8×10, вывод отсортированного массива по возрастанию, максимальный элемент.

## Состав проекта

| Файл | Назначение |
|---|---|
| `server.js` | HTTP-сервер на Node.js (встроенные модули `http`, `fs`, `path`), маршруты `/`, `/sorted`, `/api/data` и раздача статических файлов |
| `js/arrayModule.js` | Модуль бизнес-логики: генерация массива, сортировка, поиск максимума (`module.exports`) |
| `js/main.js` | Клиентский сценарий первой страницы: построение таблицы 8×10 |
| `js/sorted.js` | Клиентский сценарий второй страницы: отсортированная таблица + максимум |
| `html/index.html` | Первая страница: шапка, массив до обработки, кнопка перехода |
| `html/sorted.html` | Вторая страница: максимальный элемент, массив после обработки |
| `css/style.css` | Единый стиль оформления (CSS3: градиенты, flexbox, тени, скругления, transition) |
| `resource/logo.svg` | Тематический логотип проекта |

Запуск: `npm start` (или `node server.js`), затем открыть http://localhost:3000/.

## Как устроено

**Сервер (`server.js`):**

- `http.createServer` + маршрутизация: `/` и `/index.html` → первая страница,
  `/sorted` и `/sorted.html` → вторая, `/api/data` → JSON с данными массива;
- чтение файлов асинхронное (`fs.readFile` с колбэком);
- защита от path traversal (проверка `..`, `path.normalize`, префикс `__dirname`);
- раздача `css/`, `js/`, `resource/` с правильными `Content-Type`.

**Модуль бизнес-логики (`js/arrayModule.js`):**

- `generateArray(80, 1, 10)` — массив из 80 случайных значений от 1 до 10;
- `sortAscending(array)` — сортировка по возрастанию (`sort((a, b) => a - b)`
  на копии массива, исходный не изменяется);
- `findMax(array)` — максимальный элемент (`Math.max`);
- массив генерируется один раз при старте сервера, поэтому обе страницы
  работают с одним и тем же набором данных (`original`, `sorted`, `max`).

**Клиент (`js/main.js`, `js/sorted.js`):**

- таблица 8×10 (8 строк × 10 столбцов = 80 элементов) строится create-методами DOM
  (`createElement`, `appendChild`, `textContent`);
- каждая ячейка окрашивается по значению: `hsl`-цвет из градиента
  (синий → красный), поэтому отсортированный массив виден «радугой»;
- данные загружаются с сервера асинхронно — `fetch('/api/data')` с промисами;
- переход на вторую страницу — по нажатию кнопки «Показать отсортированный массив»
  на первой странице (`window.location.href = '/sorted'`).

## Интерфейс

- **Страница 1:** массив до обработки в таблице 8×10, кнопка перехода.
- **Страница 2:** отдельный блок «Максимальный элемент массива», отсортированный
  массив по возрастанию в таблице 8×10, кнопка возврата.
