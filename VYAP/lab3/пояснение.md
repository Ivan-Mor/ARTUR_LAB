# Лабораторная работа №3 — краткое пояснение

**Тема:** «Разработка проекта решения задач на основе динамической подгрузки данных. Классы и наследование классов».
**Вариант 2:** родительский блок div с дочерними блоками (span с заголовком + параграф), вставка новых блоков по выбору пользователя.

## Состав проекта

| Файл | Назначение |
|---|---|
| `html/index.html` | Структура страницы: шапка, панель управления, область родительского блока, панель информации |
| `css/style.css` | Единый стиль оформления (CSS3: градиенты, flexbox, тени, скругления, transition, filter) |
| `js/app.js` | Классы, коллекции Set/Map и вся логика динамического размещения блоков |
| `resource/logo.svg` | Тематическое изображение (планета с кольцами) |

Запуск: открыть `html/index.html` в браузере (сервер не нужен).

## Тематика

Космос: родительский блок — «обзор», каждый дочерний блок — карточка планеты
(заголовок — название планеты, параграф — описание 3–5 слов).

## Как устроено

**Родительский класс `BlockManager`:**

- конструктор с параметрами по умолчанию (в JS нет перегрузки конструкторов,
  поэтому «не менее 3 различных конструкторов» — это вызовы `new BlockManager()`,
  `new BlockManager('Мой блок')`, `new BlockManager('Мой блок', '#2980b9', 500)`);
- `addExtra()` — метод, добавляющий дополнительные свойства в класс (в Map `extra`);
- `makeBlock()` — построение дочернего блока create-методами DOM
  (`createElement`, `createTextNode`): div > span с заголовком h1–h6 + p;
- `placeParent()` — сценарий размещения родительского блока на странице;
- `placeInitialBlocks()` — сценарий размещения двух исходных дочерних блоков из Set;
- `fillSelect()`, `fillPositionSelect()` — заполнение выпадающих списков данными коллекций;
- `showAsList()` — вывод хранящейся информации в виде списка;
- `showAsText()` — вывод той же информации текстом.

**Дочерний класс `BlockEditor extends BlockManager`:**

- конструктор вызывает `super()` (наследование);
- `insertBlock()` — построение нового блока с заданным цветом и вставка
  в выбранную пользователем позицию через `insertBefore()` / `appendChild()`
  (используется `this` и данные из Map).

**Коллекции ECMA-6 (обработка только их методами):**

- `colors`, `titles`, `texts` — три коллекции `Set` по 8 элементов
  (цвета блоков, заголовки, содержимое параграфов);
  методы: `forEach`, `values`, свойство `size`;
- `blocksMap` — коллекция `Map` «номер блока по порядку → DOM-элемент»;
  методы: `set`, `clear`, `values`, `size`;
- `extra` — Map дополнительных свойств каждого экземпляра класса.

Создаются два экземпляра классов: `manager` (без аргументов) и `editor` (с аргументами).

## Интерфейс

- **Выпадающие списки:** позиция блока по порядку (1 … «в конец»), цвет блока (Set),
  ширина блока (200–400 px), заголовок (Set), тип заголовка h1–h6, текст параграфа (Set).
- **«Вставить блок»** — новый дочерний блок с выбранным текстом, типом заголовка,
  цветом (background) и размером вставляется в выбранную позицию родительского блока.
- **«Данные списком» / «Данные текстом»** — вывод всего, что хранится в коллекциях
  (включая номера блоков и дополнительные свойства классов), в панели «Хранимая информация».
